# 自审记录

## 已验证（Playwright 实测）
- 注册/登录/错误提示、刷新后会话保持、退出登录
- 生成（1–4 张）、占位骨架、参考图连线、预扣算力、失败自动退还（实测 100→100）
- 便签双击创建/编辑、拖动 + 撤销、缩放节点 + 撤销、上传图片、滚轮缩放、刷新后项目恢复
- 深/浅色、设置 → 模型接入、项目列表、手机宽度布局，无控制台报错

## 审查中发现并已修复
1. 双击建便签时输入被快捷键吞掉（聚焦延迟）→ 同步进入编辑
2. 编辑中再次双击会重复入栈 → 加编辑态守卫
3. 手机宽度顶栏溢出、生成按钮文字换行 → 窄屏收起次要按钮

## 迭代 2：参考 jh.token6688.com（聚合引擎 AIGC）
该站是多模型聚合平台：左侧可搜索/分类的模型库（价格、标签）、居中的大提示词框、「灵感案例」卡片一键做同款、未登录可先浏览。
已借鉴：
- 模型选择由下拉改为**模型库浮层**（搜索、说明、单价、“接入我的模型 API”入口）
- 空画布加入**灵感案例**（点击填入提示词与比例）
未做：成功率徽标（无真实数据，不造假）、无限画布/漫剧/PPT 等多智能体入口（超出本期范围）。

## 迭代 3：服务端（把收费做实）
新增 `server/`：账号（scrypt 哈希、会话令牌只存哈希、登录限流）、算力（SQLite 事务，余额不会扣成负数）、出图代理（Key 只在服务端；先扣后生成，失败退还）、订单与支付回调（HMAC 校验、幂等）、管理员加减算力脚本；静态托管仅暴露 `index.html` 与 `src/`。
实测：未登录 401；重复注册 409；错误密码 8 次后 429；余额耗尽后 402；路径穿越与直接下载数据库均 404；回调错误签名 401、重复通知不重复加款；浏览器端到端（注册→生成→刷新→充值→退出→错误登录）通过。

### 仍需你来做的事（我无法替你完成）
| 项 | 原因 |
|---|---|
| 接入真实支付通道 | 需要你的商户资质与密钥；回调协议已就绪，只需把通知转成 `{orderId,status:"paid"}` 并签名 |
| 配置真实模型 Key 与定价 | 需要你的上游账号；改 `server/models.json` |
| HTTPS 与域名、数据备份 | 部署环境相关 |
| 图片对象存储 | 用户量上来后再做；当前图片随项目存在用户浏览器 IndexedDB，换设备不同步 |
| 隐私政策/用户协议、实名与内容合规 | 国内上线 AIGC 服务通常需要，请按你所在地区要求处理 |
