# 自审记录

## 已验证（Playwright 实测）
- 注册/登录/错误提示、刷新后会话保持、退出登录
- 生成（1–4 张）、占位骨架、参考图连线、预扣算力、失败自动退还（实测 100→100）
- 便签双击创建/编辑、拖动 + 撤销、缩放节点 + 撤销、上传图片、滚轮缩放、刷新后项目恢复
- 深/浅色、设置 → 模型接入、项目列表、手机宽度布局，无控制台报错

## 审查中发现并已修复
1. 双击建便签时输入被快捷键吞掉（聚焦延迟）→ 同步进入编辑
2. 编辑中再次双击会重复入栈 → 加编辑态守卫
3. 手机宽度顶栏溢出、生成按钮文字换行 → 窄屏收起次要按钮

## 已知不足 / 后续
| 项 | 说明 | 建议 |
|---|---|---|
| **账号与算力不安全** | 目前存于浏览器 localStorage，用户可自行改余额 | 收费上线前必须接后端（契约见 PLAN §4），扣费与出图放服务端 |
| API Key 在浏览器 | 仅适合自己调试 | 服务端代理 |
| 图片以 dataURL 存 IndexedDB | 项目很大时变慢 | 后端对象存储 + CDN |
| 无吸附/对齐线、分组、图层面板 | 本期不做 | 下一期 |
| 无局部重绘/涂抹、放大、去背景 | 需要对应模型 API | 接入后在节点工具栏扩展 |
| 无多人协作 | — | 需后端 + CRDT |
| 演示出图为程序化抽象图 | 仅用于验证交互 | 配置自定义模型后即为真实出图 |
